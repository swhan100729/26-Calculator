## 1. 프로젝트 개요 및 목적
- **목표**: Streamlit Cloud 환경에서 구동 가능한 학생용 스마트 학습 타이머 및 플래너 애플리케이션 개발
- **개발 환경 / 라이브러리**: Python, Streamlit, Pandas, Plotly

---

## 2. 대화 진행 및 개발 경과

### 📍 1단계: 기본 학습 타이머 애플리케이션 개발
- **요구사항**:
  - 시작, 일시정지, 재개, 초기화 및 과목별 시간 저장 기능
  - Plotly를 활용한 과목별 누적 시간 막대 그래프 및 진행 타임라인 시각화
  - 기본 To-Do List 포함
- **구현 내용**: `st.session_state`를 기반으로 한 시간 측정 및 실시간 갱신($HH:MM:SS$ 포맷) 구조 작성.

### 📍 2단계: 다중 페이지 사이드바 메뉴 도입
- **요구사항**:
  - 사이드바 네비게이션 메뉴 추가 ("⏱️ 공부 타이머", "✅ 오늘 할일", "📝 공부 회고")
  - '공부 타이머'에 기존 기능 통합, 나머지 메뉴는 준비 중 안내 표기
- **구현 내용**: `st.sidebar.radio`를 적용하여 메뉴 변경 시에도 학습 데이터 및 타이머 상태가 영구 유지되도록 구성.

### 📍 3단계: '오늘 할일' 관리 기능 고도화
- **요구사항**:
  - 과목 선택 + 할 일 내용 입력 후 추가 버튼으로 등록
  - 완료 체크박스 선택 시 취소선(~~텍스트~~) 적용 및 달성률 프로그레스 바 표시
  - 전체 소스코드 제공
- **구현 내용**:
  - `st.form` 내 3열 레이아웃으로 입력 UX 개선
  - 체크박스 클릭 이벤트 시 Markdown 취소선(`~~`) 동적 렌더링 로직 추가
